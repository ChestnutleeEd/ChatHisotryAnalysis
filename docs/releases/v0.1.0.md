# Chat History Analysis v0.1.0 Alpha

首个可下载的 macOS Alpha 版本。聊天数据从导入、预处理、分析到导出都在本机完成，不上传、不需要账号，也不依赖用户安装 Python、Node.js 或 Conda。

## 主要功能

- 导入一个或多个 CipherTalk `detailed-json` 年度源，并可单独添加 overlap verification 源；
- 严格输入校验、流式预处理、跨文件确定性合并与去重；
- 年度回顾：规模、节奏、双方平衡、交流、词汇与本地回顾卡；
- 详细分析：概览、趋势、双方比较、活跃时间、词汇与年份、消息类型、回复与会话、导出；
- 日期、发送方、年份、词频呈现和 1/3/6/12/24 小时会话阈值筛选；
- 聚合 JSON、CSV、图表 PNG 与分享卡 PNG 导出；
- UTC+08:00 确定性统计口径、可访问表格和响应式界面；
- 本地临时会话、取消/重试/替换、退出清理与启动恢复。

完整安装和使用说明见项目 [README](https://github.com/ChestnutleeEd/ChatHisotryAnalysis#readme)。

## 安装提示

把 DMG 中的 `Chat History Analysis.app` 拖到“应用程序”。此 Alpha 使用 ad-hoc 签名，未经过 Apple Developer ID 签名或 notarization；首次启动请在 Finder 中右键应用选择“打开”，不要全局关闭 Gatekeeper。

## 已知限制

- 仅支持 macOS arm64，不支持 Intel Mac 和 Windows；
- 仅支持 CipherTalk `detailed-json`；
- ad-hoc 签名，未 notarize，未提供自动更新；
- 当前为 Alpha，不代表正式发布级 supply-chain、安全、最大容量或 p95 性能认证；
- 导出不含聊天正文，但聚合统计仍可能敏感，请谨慎分享。
