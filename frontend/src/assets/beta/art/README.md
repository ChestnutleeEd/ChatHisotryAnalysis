# Beta generated art

These are the selected, optimized, repository-owned decorative assets for Visual Re-architecture V1. They contain no user-derived content and are never used as a data source.

## Selection

- `annual-opening-hero-v1.webp` — selected from three synthetic candidates. The selected 3:2 landscape keeps the left side quiet for the year, range, lead, and metric overlay while its layered paths and right-side density field carry the Private Data Atelier direction into a 4:3 or 5:4 crop. Shipping size is 1536×1024 and approximately 84 KiB.
- `closing-poster-v1.webp` — selected from three synthetic candidates. The selected 4:5 poster keeps the left side open for the closing statement and local-only copy while the layered planes and continuing path carry the story forward. Shipping size is 1122×1402 and approximately 204 KiB.
- `share-card-field-v1.webp` — selected from three new synthetic 4:5 candidates for B5.2. Candidate 1 had the richest perimeter collage but a dark edge patch pulled attention; candidate 2 had the quietest center but insufficient edge rhythm; candidate 3 kept a large text-safe center while thin moss/coral paths and mineral paper strata carried the edge field without becoming a subject. Shipping size is 1200×1500 and 113,562 bytes.

Rejected candidates remain only in the tool-owned review directory and are not tracked in the repository.

## Prompt boundary

All nine candidates used the `stylized-concept` use case with generic, synthetic, abstract editorial briefs. Prompts specified matte cut-paper/raster texture, the bounded sand/sage/clay/terracotta/ochre/moss/ink palette, negative space for DOM overlays, and explicit 3:2 or 4:5 crop behavior. Every prompt prohibited text, numbers, dates, years, logos, watermarks, people, faces, avatars, chat UI, messages, locks, shields, cloud-security clichés, romantic imagery, photorealism, glossy 3D, neon AI, and literal private data.

Final prompt briefs used for the selected candidates:

- `annual-opening-hero`: “Stylized-concept abstract editorial landscape for a private local data atelier; matte cut-paper layers, quiet left-side negative space, flowing time/rhythm paths and a denser right-side field, sand/sage/clay/terracotta/ochre/moss/ink palette, 3:2 landscape crop; no text, numbers, people, UI, literal data, security symbols, logos, or watermark.”
- `closing-poster`: “Stylized-concept abstract editorial poster for a private local data atelier; matte cut-paper strata rising toward a continuing path, open left-side space for DOM copy, warm sand with sage/ochre/terracotta/moss/ink layers, 4:5 portrait crop; no text, numbers, people, UI, literal data, security symbols, logos, or watermark.”
- `share-card-field-v1`: “Stylized-concept abstract archival edge field for a private local annual recap card; matte paper strata, thin mineral-colored paths, restrained dot rhythms near the perimeter, a large uninterrupted paper center for deterministic facts, warm parchment/sand with moss/deep green/muted clay/coral/charcoal and restrained pale aqua, 4:5 portrait; no text, pseudo-lettering, numbers, people, UI, literal data, security symbols, logos, or watermark.” Three candidates were reviewed in the responsive preview; no refinement was needed.

## Runtime boundary

The assets are imported from the local bundle, given explicit intrinsic dimensions/aspect ratios, marked decorative with empty alt text and `aria-hidden`, and paired with a CSS fallback. There is no runtime generation, remote URL, CDN, remote font, or network fetch.
